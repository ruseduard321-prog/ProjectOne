# ProjectOne Engineering Handbook

## Chapter 9 — Security Standards

### Objective

Security is built into every layer.

### Identity

Authenticate every request and authorize every action.

See also: [[Authentication and Authorization]]

### Secrets

Never store secrets in source control.

### Logging

Audit sensitive actions without exposing secrets.

### OWASP

Follow current OWASP recommendations.

### Summary

Protect users through defense in depth.
