# ProjectOne Engineering Handbook

## Chapter 7 — Database Standards

### Objective

Database design prioritizes integrity, performance and scalability.

### Naming

Use consistent singular/plural conventions and descriptive names.

### Migrations

All schema changes are version controlled.

### Indexes

Index only measured bottlenecks and common query paths.

### RLS

All tenant data is protected through Row Level Security.

See also: [[Authentication and Authorization]]

### Summary

Data remains secure, normalized and maintainable.
