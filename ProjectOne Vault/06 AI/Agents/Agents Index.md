# Agents Index

No individual agent definitions exist yet. Per [[Agent Architecture]], ProjectOne's core agent types are: Planning Agent, Research Agent, Script Agent, Media Generation Agent, Video Assembly Agent, Quality Assurance Agent, Publishing Agent, Analytics Agent, and Strategy Agent.

Each, once defined here, must specify: single responsibility, inputs/outputs, success criteria, execution logging, and its position in the [[CLAUDE|CLAUDE.md]] Section 15 default approval policy (which of its actions require explicit user approval vs. may run autonomously).
