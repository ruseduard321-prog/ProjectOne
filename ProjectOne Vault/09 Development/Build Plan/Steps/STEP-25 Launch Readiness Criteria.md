# STEP-25 — Launch Readiness Criteria

**Status:** Not Started
**Detail level:** outline — expanded to full detail by [[STEP-24 Dashboard]], per [[Execution Protocol]].

## Goal

Define and then verify what "public release" actually means. [[Release Strategy]] names internal/alpha/beta/stable entry and exit criteria but never defines them — this step writes that definition into the canonical note, then audits the build against it.

## Scope

Also resolves the open scope question: **is the first public release free/invite-only, or does it charge?** If it charges, [[Billing]] steps are inserted before STEP-26 — an owner decision, not something Claude settles alone. Covers security review, performance verification, backup/restore validation, and the [[Compliance and Governance]] obligations that must exist before real users arrive.
